# Installer Coach Conseil sur l'iPhone

## Une seule fois : activer GitHub Pages

1. Sur GitHub, ouvre le dépôt **coach** → **Settings** → **Pages**.
2. Dans **Build and deployment → Source**, choisis **GitHub Actions**.
3. Va dans l'onglet **Actions** et relance le dernier « Déployer sur GitHub
   Pages » (ou pousse un commit sur `main`).
4. L'adresse du site est : **https://rayannnouuuu.github.io/coach/**

> GitHub Pages gratuit demande un dépôt **public**. C'est prévu : le contenu
> n'est pas confidentiel et l'app ne contient aucune donnée client. Tes
> réécritures, ta progression et tes objectifs restent sur le téléphone,
> jamais sur GitHub.

## Sur l'iPhone

1. Ouvre **https://rayannnouuuu.github.io/coach/** dans **Safari** (pas Chrome :
   seul Safari peut installer une app web sur iPhone).
2. Touche le bouton **Partager** (carré avec une flèche) → **Sur l'écran
   d'accueil** → **Ajouter**.
3. Lance l'app depuis l'icône : elle s'ouvre en plein écran, sans barre Safari.
4. Navigue une fois dans chaque onglet : tout est alors disponible **hors ligne**.

## Mises à jour

Quand je pousse une nouvelle version (nouveau contenu, corrections), un
bandeau « Nouvelle version disponible » apparaît au prochain lancement.
Touche **Mettre à jour** quand tu veux : rien n'est rechargé de force.

## Sauvegarder ses données

Onglet **Plus** → **Exporter** → dans la feuille de partage, **Enregistrer
dans Fichiers** → **iCloud Drive**. Pour restaurer (nouveau téléphone,
données effacées) : **Plus** → **Importer** → choisir le fichier.

Bon à savoir : Safari peut effacer les données d'un site non utilisé pendant
plusieurs semaines. Une app ajoutée à l'écran d'accueil est mieux protégée,
mais exporte quand même une fois par mois (l'app te le rappelle).
